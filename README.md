# Data Mining — Coursework

Lab notebooks from the **Data Mining** course at FAST-NUCES, covering the standard pipeline from preprocessing through to clustering and classification.

## Topics covered

Data cleaning and missing-value handling · normalisation and encoding · association rules (Apriori) · classification (decision trees, k-NN, Naive Bayes) · clustering (K-Means, hierarchical, DBSCAN) · evaluation metrics and cross-validation
